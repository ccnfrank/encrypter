    How to use encryter.app

    1. Add your files Drop files or folders in the area above, or use Choose files / Choose folder. Folders and multiple items are zipped first.
    2. Let the app pick the action Files that are not encrypted yet get encrypted. Files already encrypted with Encryter get decrypted.
    3. Set a password Use at least 8 characters and type it twice. Without it, the file cannot be opened again.
    4. Optional: delete the original Check the box to remove the original after encrypting. Deleted files are not sent to the Trash.
    5. Choose where to save Click the button and pick the name and folder. Encrypted files keep the original name with .enc added. Decrypted files get their original name and extension back.

    Saving to a chosen folder and deleting originals work in Chrome and Edge. In other browsers, the file is downloaded and the delete option is turned off.
